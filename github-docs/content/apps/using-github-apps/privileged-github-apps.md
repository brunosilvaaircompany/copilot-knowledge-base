# Privileged GitHub Apps

Some GitHub Apps are privileged apps. These apps are owned by GitHub and are granted special capabilities. For example, users can authorize these apps and use them to access data from an organization without requiring approval by the organization.

Some of these privileged apps are automatically included with GitHub and do not require user authorization. These apps will not appear in your list of authorized GitHub Apps or in your list of installed GitHub Apps.Enterprise Managed Users are allowed to install these privileged apps on their user account, while standard, unprivileged apps cannot be installed on Enterprise Managed Users user accounts.

These privileged apps will appear in the user security log, but will not appear in organization or enterprise audit logs. For more information, see [Reviewing Your Security Log](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/reviewing-your-security-log), [Reviewing The Audit Log For Your Organization](https://docs.github.com/en/organizations/keeping-your-organization-secure/managing-security-settings-for-your-organization/reviewing-the-audit-log-for-your-organization), and [Audit Log For An Enterprise](https://docs.github.com/en/admin/concepts/security-and-compliance/audit-log-for-an-enterprise).

These GitHub Apps are:

* Actions
* Dependabot
* Git Src Migrator
* GitHub Advanced Security
* GitHub Classroom
* GitHub Codespaces
* GitHub Copilot Plugin
* GitHub Merge Queue
* GitHub Pages
* GitHub Project Automation
* GitHub Team Synchronization
* Microsoft Teams for GitHub
* OpenGraph (`custom-og-image`)
* Slack
