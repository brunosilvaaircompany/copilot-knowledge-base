# REST API endpoints for Dependabot alerts

> [!NOTE]
> The ability to use the REST API to manage Dependabot alerts is currently in public preview and subject to change.

## About Dependabot alerts

You can view Dependabot alerts for a repository and update individual alerts with the REST API. For more information, see [Dependabot Alerts](https://docs.github.com/en/code-security/concepts/supply-chain-security/dependabot-alerts).
