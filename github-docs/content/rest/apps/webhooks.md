# REST API endpoints for GitHub App webhooks

## About webhooks for GitHub Apps

A GitHub App's webhook allows your server to receive HTTP `POST` payloads whenever certain events happen for a GitHub App. For more information, see [Webhooks](https://docs.github.com/en/webhooks) and [Using Webhooks With GitHub Apps](https://docs.github.com/en/apps/creating-github-apps/registering-a-github-app/using-webhooks-with-github-apps).
