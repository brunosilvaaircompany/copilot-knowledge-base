# REST API endpoints for Copilot usage metrics

To enable these endpoints, the "Copilot usage metrics" policy must be set to **Enabled everywhere** for the enterprise. See [Manage Enterprise Policies](https://docs.github.com/en/copilot/how-tos/administer-copilot/manage-for-enterprise/manage-enterprise-policies#defining-policies-for-your-enterprise).

For more information on the metrics returned by these endpoints, see [Copilot Usage Metrics](https://docs.github.com/en/copilot/reference/copilot-usage-metrics).
