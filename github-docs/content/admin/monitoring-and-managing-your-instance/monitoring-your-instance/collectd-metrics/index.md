# Collectd metrics

Collectd metrics are gathered by default and are fully supported in this release. OpenTelemetry metrics are the future foundation for monitoring, available from GitHub Enterprise Server 3.18 onward.

> [!IMPORTANT]
> Collectd metrics are retired in GitHub Enterprise Server 3.23. We recommend migrating to OpenTelemetry metrics before upgrading. See [Migration Guidance](https://docs.github.com/en/admin/monitoring-and-managing-your-instance/monitoring-your-instance/opentelemetry-metrics/migration-guidance).
