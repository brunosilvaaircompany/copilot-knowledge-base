# About repository graphs

A repository's graphs give you information on  traffic, projects that depend on the repository, contributors and commits to the repository, and a repository's forks and network. If you maintain a repository, you can use this data to get a better understanding of who's using your repository and why they're using it.



> [!NOTE]
> Certain contributor, commit, and code frequency insights are only available for repositories that have fewer than 10,000 commits.






Repository insights is a separate experience under the **Insights** tab for organization-owned repositories. It shows pull request activity and Copilot code review outcomes to help you identify review coverage gaps and opportunities to improve review practices. Its access requirements are separate from the graph availability described below. For prerequisites and navigation, see [View Repository Insights](https://docs.github.com/en/copilot/how-tos/administer-copilot/view-repository-insights). For metric definitions and interpretation, see [Repository Insights Metrics](https://docs.github.com/en/copilot/reference/copilot-usage-metrics/repository-insights-metrics).

Some repository graphs are available only in public repositories with GitHub Free:
* Pulse
* Contributors
* Traffic
* Commits
* Code frequency
* Network

All other repository graphs are available in all repositories. Every repository graph is available in public and private repositories with GitHub Pro, GitHub Team, and GitHub Enterprise Cloud. See [Githubs Plans](https://docs.github.com/en/get-started/learning-about-github/githubs-plans).
