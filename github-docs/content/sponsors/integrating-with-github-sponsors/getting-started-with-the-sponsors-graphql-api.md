# Getting started with the Sponsors GraphQL API

To get started with the GraphQL API, see [Introduction To GraphQL](https://docs.github.com/en/graphql/guides/introduction-to-graphql).

You can find the details about the Sponsors GraphQL API in the reference docs. For more information, see [Reference](https://docs.github.com/en/graphql/reference). We recommend using the GraphQL clients to build your GraphQL calls. For more information, see [Using GraphQL Clients](https://docs.github.com/en/graphql/guides/using-graphql-clients).

## Known Issues

The `createSponsorship` mutation currently does not work for one-time payments. [Reproduction steps and discussion here](https://github.com/orgs/community/discussions/138161)
