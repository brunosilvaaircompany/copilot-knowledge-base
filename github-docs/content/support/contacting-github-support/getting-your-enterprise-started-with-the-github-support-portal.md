# Getting your enterprise started with the GitHub Support portal

## About the GitHub Support portal for enterprises



Anyone can use the [GitHub Support portal](https://support.github.com/) to view and manage support tickets about GitHub, but there are special steps to follow before using the [GitHub Support portal](https://support.github.com/) to create tickets about an enterprise account.

The GitHub Support portal offers single sign-on (SSO) connected to your GitHub account.

If your institution has an enterprise account on GitHub.com, you have a user account on GitHub.com, and that user account has been granted support entitlements for the enterprise account, you can select the enterprise account when creating a ticket. ## Getting started with the GitHub Support portal

Before you start creating tickets associated with your enterprise account on GitHub.com, we recommend completing the following steps.

1. Identify the user on GitHub.com who is an owner of your enterprise account.
1. Configure a verified domain. For more information, see [Verifying Or Approving A Domain For Your Enterprise](https://docs.github.com/en/admin/configuring-settings/configuring-user-applications-for-your-enterprise/verifying-or-approving-a-domain-for-your-enterprise).
1. Add owners, billing managers, or support-entitled members to your enterprise account. For more information, see [Inviting People To Manage Your Enterprise](https://docs.github.com/en/enterprise-cloud@latest/admin/managing-accounts-and-repositories/managing-users-in-your-enterprise/inviting-people-to-manage-your-enterprise) and [Managing Support Entitlements For Your Enterprise](https://docs.github.com/en/enterprise-cloud@latest/admin/managing-accounts-and-repositories/managing-users-in-your-enterprise/managing-support-entitlements-for-your-enterprise).
