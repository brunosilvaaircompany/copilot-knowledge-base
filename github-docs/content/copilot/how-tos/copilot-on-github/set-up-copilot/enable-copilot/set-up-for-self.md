# Setting up GitHub Copilot for yourself

## Get access to GitHub Copilot

Copilot Free gives you up to 2,000 code completions and limited access to select Copilot features, allowing you to try AI-powered coding assistance at no cost. [Start using Copilot Free](https://github.com/copilot?ref_product=copilot&ref_type=engagement&ref_style=text&ref_plan=free).

For higher limits and access to more models, subscribe to **Copilot Pro**, **Copilot Pro+**, or **Copilot Max**. See [Get Started With A Copilot Plan](https://docs.github.com/en/copilot/how-tos/manage-your-account/get-started-with-a-copilot-plan) for details on all plans, including free options for students, teachers, and open source maintainers.

## Configure settings (optional)

If you have your own Copilot plan, manage your policies and feature access from your [Copilot settings](https://github.com/settings/copilot?ref_product=copilot&ref_type=engagement&ref_style=text). You can also enable Copilot Memory so Copilot remembers useful context about your repositories.

## Set up personal custom instructions (optional)

Personal custom instructions tell Copilot Chat about your preferences — such as your preferred language, coding style, or response format. To add them, open any Copilot Chat conversation on GitHub, click your profile picture, and select **Personal instructions**. For more information, see [Add Personal Instructions](https://docs.github.com/en/copilot/how-tos/copilot-on-github/customize-copilot/add-custom-instructions/add-personal-instructions).
