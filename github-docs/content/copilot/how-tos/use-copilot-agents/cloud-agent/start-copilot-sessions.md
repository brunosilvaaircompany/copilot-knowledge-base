# Starting GitHub Copilot sessions

You can start Copilot cloud agent from several clients. Choose the one that fits your workflow:

* [GitHub](/copilot/how-tos/use-copilot-agents/cloud-agent/use-cloud-agent-on-github) — issues, agents tab, dashboard, Copilot Chat, new repositories, and failing GitHub Actions runs
* [GitHub Mobile](/copilot/how-tos/use-copilot-agents/cloud-agent/use-cloud-agent-on-mobile)
* [IDEs](/copilot/how-tos/use-copilot-agents/cloud-agent/use-cloud-agent-in-your-ide) — Visual Studio Code, JetBrains, Eclipse, and Visual Studio 2026
* [REST API](/copilot/how-tos/use-copilot-agents/cloud-agent/use-cloud-agent-via-the-api)
* [GitHub CLI](/copilot/how-tos/use-copilot-agents/cloud-agent/use-cloud-agent-from-cli)
* [GitHub MCP Server](/copilot/how-tos/use-copilot-agents/cloud-agent/use-cloud-agent-with-mcp)
* [Jira](/copilot/how-tos/use-copilot-agents/cloud-agent/integrate-cloud-agent-with-jira)
* [Slack](/copilot/how-tos/use-copilot-agents/cloud-agent/integrate-cloud-agent-with-slack)
* [Microsoft Teams](/copilot/how-tos/use-copilot-agents/cloud-agent/integrate-cloud-agent-with-teams)
* [Azure Boards](/copilot/how-tos/use-copilot-agents/cloud-agent/integrate-cloud-agent-with-azure-boards)
* [Linear](/copilot/how-tos/use-copilot-agents/cloud-agent/integrate-cloud-agent-with-linear)
* [Raycast](/copilot/how-tos/use-copilot-agents/cloud-agent/use-cloud-agent-from-raycast)

You can also start sessions automatically, on a schedule or in response to events such as an issue being opened, by setting up an automation. See [Create Automations](https://docs.github.com/en/copilot/how-tos/use-copilot-agents/cloud-agent/create-automations).

Copilot will start working on the task in the background. Some entry points open a pull request automatically. In other cases, you can prompt Copilot to open a pull request, or create a pull request when Copilot finishes work, from the session logs.

For more information, see [About Cloud Agent](https://docs.github.com/en/copilot/concepts/agents/cloud-agent/about-cloud-agent).
