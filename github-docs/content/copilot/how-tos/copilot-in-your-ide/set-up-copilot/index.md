# Set up Copilot

These articles explain how to install Copilot in your IDE and configure it for your environment.

Before you start, you need access to GitHub Copilot through a free or paid plan, or through an organization or enterprise. See [Get Started With A Copilot Plan](https://docs.github.com/en/copilot/how-tos/manage-your-account/get-started-with-a-copilot-plan).
