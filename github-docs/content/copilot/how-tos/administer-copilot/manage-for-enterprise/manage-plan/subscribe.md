# Subscribing to GitHub Copilot for your enterprise

## Paying by credit card or PayPal

>[!NOTE] If you are currently in a trial of GitHub Enterprise Cloud, you must convert to a paid enterprise before you can purchase GitHub Copilot.

1. Ensure you are signed in as an enterprise admin on GitHub.
1. Navigate to the [GitHub Copilot sign up page](https://github.com/github-copilot/purchase?ref_product=copilot&ref_type=purchase&ref_style=button&ref_plan=enterprise).
1. Ensure you are making changes to the right enterprise account. If you are not, click **{% octicon "arrow-switch" aria-hidden="true" aria-label="arrow-switch" %} Switch** and select the enterprise for which you want to purchase GitHub Copilot. You can also append `&enterprise=YOUR-ENTERPRISE` to the URL to pre-select the enterprise.
1. Follow the steps to sign up and enable Copilot for organizations in your enterprise. If you purchased Copilot Enterprise, you will be able to assign either Copilot Enterprise or Copilot Business to each individual organization in the enterprise.

## Other payment methods

>[!NOTE]
> If you're under a Microsoft Enterprise Agreement, you need to connect your Azure subscription ID to your enterprise account to enable and pay for GitHub Copilot. For more information, see [Connect Azure Sub](https://docs.github.com/en/billing/how-tos/set-up-payment/connect-azure-sub).


1. To purchase GitHub Copilot for your enterprise, [contact GitHub's Sales team](https://github.com/enterprise/contact?ref_product=copilot&ref_type=engagement&ref_style=text).
1. A member of the Sales team will work with you to set up Copilot for your enterprise.
