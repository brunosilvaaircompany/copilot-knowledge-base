# GitHub Copilot request-based billing for annual plan subscribers (legacy)

> [!IMPORTANT] On June 1, 2026, GitHub moved to usage-based billing. The articles in this category, which refer to GitHub's legacy premium request-based billing model, only apply to Copilot Pro and Copilot Pro+ subscribers on an existing **annual plan** who remain on **request-based billing** after June 1, 2026.
