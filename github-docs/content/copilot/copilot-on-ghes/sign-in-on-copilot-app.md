# Signing in to GitHub Enterprise Server in the GitHub Copilot app

If you use GitHub Enterprise Server, you can sign in on the Copilot app to work with repositories, pull requests, and issues hosted on the GitHub Enterprise Server instance.

When you set up the app, you must first sign in to an account on GitHub.com or GHE.com. Then, you can add your GitHub Enterprise Server account:

1. Click <span style="vertical-align: 2px">{% octicon "gear" aria-label="Settings" %}</span> to open the Settings dialog.
1. In the sidebar, click **Accounts**.
1. Click **Add account**, then click **GitHub Enterprise Server**.
1. Follow the prompts to open your browser and authorize the app.

## Next step

To start making requests, ensure you're also signed in to a cloud account with a Copilot license. Alternatively, to configure your own model provider, see [Add Llm Models](https://docs.github.com/en/enterprise-cloud@latest/copilot/how-tos/github-copilot-app/add-llm-models).
