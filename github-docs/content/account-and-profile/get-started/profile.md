# Profile

## About your GitHub profile

Your profile is how other people discover and learn about you on GitHub. You can customize your profile to highlight your best work and share more about yourself.

* For a general tutorial on personalizing your profile, see [Personalize Your Profile](https://docs.github.com/en/account-and-profile/tutorials/personalize-your-profile).
* For more specific profile customization, see [How Tos](https://docs.github.com/en/account-and-profile/how-tos).
* For reference information, see [Profile Reference](https://docs.github.com/en/account-and-profile/reference/profile-reference).
