# Managing your tab size rendering preference

If you feel that tabbed indentation in code rendered on GitHub takes up too much, or too little space, you can change this in your settings.

1. In the upper-right corner of any page on GitHub, click your profile picture, then click **{% octicon "gear" aria-hidden="true" aria-label="gear" %} Settings**.

1. In the left sidebar, click **{% octicon "paintbrush" aria-hidden="true" aria-label="paintbrush" %} Appearance**.
1. Scroll down to "Tab size preference" and use the dropdown menu to choose your preference.
