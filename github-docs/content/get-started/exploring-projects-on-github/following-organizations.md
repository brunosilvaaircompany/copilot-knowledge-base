# Following organizations

> [!NOTE]
> The ability to follow organizations is currently in public preview and subject to change.


## About followers

When you follow organizations on GitHub, you'll see their public activity on your personal dashboard. This activity includes new discussions, sponsorships, and repositories.
 For more information, see [Personal Dashboard Quickstart](https://docs.github.com/en/account-and-profile/get-started/personal-dashboard-quickstart#staying-up-to-date-with-activity-from-the-community).

You can unfollow an organization if you do not wish to see their public activity on GitHub.

## Following an organization

1. Go to the organization page you want to follow.
1. In the top-right corner, click **Follow**.

## Unfollowing an organization

1. Go to the organization page you want to unfollow.
1. In the top-right corner, click **Unfollow**.

## Viewing people and organizations a user follows

1. Navigate to the user's profile page.

1. Under the user's profile picture, click **following**.
