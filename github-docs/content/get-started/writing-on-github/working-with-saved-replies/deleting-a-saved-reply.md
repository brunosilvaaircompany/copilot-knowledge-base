# Deleting a saved reply

1. In the upper-right corner of any page on GitHub, click your profile picture, then click **{% octicon "gear" aria-hidden="true" aria-label="gear" %} Settings**.

1. In the sidebar, under "Code, planning, and automation",
 click **{% octicon "reply" aria-hidden="true" aria-label="reply" %} Saved replies**.

1. Under "Saved replies", next to the saved reply you want to delete, click {% octicon "x" aria-label="The X" %}.
