# Finding your discussions

## Finding discussions

1. In the top-left corner of GitHub, select {% octicon "three-bars" aria-label="Open global navigation menu" %}, then click **{% octicon "comment-discussion" aria-hidden="true" aria-label="comment-discussion" %} Discussions**.

   ![Screenshot of the navigation bar on GitHub. The "Open global navigation menu" icon is outlined in dark orange.](/assets/images/help/navigation/global-navigation-menu-icon.png)

1. Toggle between **Created** and **Commented** to see the discussions you've created or participated in.
