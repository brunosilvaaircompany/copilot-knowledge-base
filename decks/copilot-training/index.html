Fundamentos

O que é o GitHub Copilot

Um assistente de programação com IA integrado ao seu fluxo.

  • Sugere código e testes direto no editor, no chat e no terminal
  • Entende o contexto do repositório aberto
  • Funciona com várias linguagens e frameworks
  • Disponível no VS Code, JetBrains, Visual Studio e no github.com
GitHub Copilot

Superfícies

Onde o Copilot aparece

Quatro pontos de entrada no fluxo de trabalho.

  • Chat — perguntas e explicações sobre o código
  • Inline no editor — sugestões enquanto você digita
  • Terminal — geração e explicação de comandos
  • Agentes — tarefas de várias etapas

Boas práticas

Hábitos que aumentam a precisão das respostas.

Contexto

Economia de contexto

Menos ruído no contexto, mais precisão na resposta.

  • Feche arquivos que não são relevantes para a tarefa
  • Limpe conversas antigas antes de iniciar um novo assunto
  • Prefira autocomplete para tarefas simples
  • Nomeie variáveis e escreva comentários com clareza
